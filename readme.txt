A bold agency and business block theme with transparent and business headers, portfolio, team and testimonial sections, and a library of patterns.

== Description ==

Addax is a block theme for agencies, studios and businesses. It ships with a modern lavender design with bold Plus Jakarta Sans headings, three header styles (standard, transparent and business with a top bar), two footers, a blog with sidebar, and templates for landing pages, full-width pages and pages with a sidebar.

More than twenty-five patterns cover a hero with floating avatars, client logos, pastel service cards, a how-it-works section, stats, an about split, a work showcase, team, process steps, testimonials, FAQ, a call to action, latest posts and contact details, plus ready-made Agency home, About and Contact pages. Everything is built from core blocks and can be edited in the Site Editor.

The theme includes Midnight, Coral and Classic style variations and extra block styles for buttons, headings, paragraphs, details (accordion), groups, images, lists and post grids.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Search for Addax, then click Install and Activate.
3. Go to Appearance > Editor to customize templates, patterns and styles.

To build a home page like the demo, create a page, choose the "Landing (transparent header)" template, insert the "Agency home page" pattern and set the page as your homepage under Settings > Reading.

== Frequently Asked Questions ==

= Does Addax need a plugin? =

No. Every pattern and template uses core blocks only.

= How do I change the header style? =

Open Appearance > Editor > Templates, edit a template and replace its header template part with "Header (transparent overlay)" or "Header (business, with top bar)".
